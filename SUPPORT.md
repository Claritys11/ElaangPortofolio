# Support

For setup and usage help:

1. Read [README.md](./README.md) or [README.id.md](./README.id.md).
2. Check existing issues.
3. Open a bug report or feature request with the provided templates.

For security-sensitive issues, do not open a public issue. Follow [SECURITY.md](./SECURITY.md).

This project does not currently offer guaranteed response times or stable release support.
